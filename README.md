# NÖCÄFF Claw Machine (3D / VR)

Pastel-pink 3D claw catcher featuring NÖCÄFF drink cans. Play in the browser with keyboard, mouse, touch, or gamepad. WebXR **Enter VR** / **Enter AR** buttons appear when your device supports them.

## Play

Open `index.html` locally, or use the GitHub Pages / raw.githack link.

## Controls

| Control | Action |
|--------|--------|
| Button **1** / key `1` | Drop claw |
| Button **2** / key `2` | Insert coin |
| Button **3** / key `3` | Orbit camera |
| Button **4** / key `4` | Pause |
| Button **5** / key `5` | Mute |
| Button **6** / key `6` | VR Look (mouse-look) |
| Joystick / WASD / Arrows | Move claw |
| Numpad `8 4 6 2` | Move · Numpad `5` drop |
| Drag playfield | Orbit / look |
| Gamepad | Stick move · face buttons map to 1–6 |

Three.js loads from jsDelivr CDN; if WebGL is unavailable, a 2D canvas fallback runs.
